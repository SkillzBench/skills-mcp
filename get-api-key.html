Keys

Get your Skills MCP API key

Three steps, under two minutes. The key looks like sb_live_… and is shown exactly once.

1 — Create a free account

Sign up at skillzbench.com/signup and verify your email. Email verification is required before keys can be minted.

2 — Add an agent

Open skillzbench.com/app and create an agent (for example "work-laptop" or "claude-code"). An agent is one loadout: the set of skills you enable for one client. You can have several — each with its own key and toggles.

3 — Mint a key

On the agent's page, create an API key. Copy it immediately — the site stores only a hash and never shows it again. That's deliberate: a leaked key can be revoked and replaced, not recovered.

Connect

claude mcp add --transport http skillzbench https://mcp.skillzbench.com/mcp \
  --header "Authorization: Bearer sb_live_YOUR_KEY"

Or use the CLI, which validates the key and writes the config for you:

npx skillzbench init   # paste key, get client snippets
npx skillzbench sync  # list / enable / disable skills

Key rules

  • One key per agent. Scopes: skills:read, skills:toggle, outcomes:write.
  • Never in URLs. The MCP accepts the key only in the Authorization header.
  • Rate limits: 120 requests/minute per key, 30 searches/minute.
  • Lost it? Revoke and mint a new one from the same page.
