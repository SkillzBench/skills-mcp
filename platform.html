What SkillzBench does

Agent skills are instructions your coding assistant or AI agent loads to get better at a specific job — writing YouTube scripts, running browser tests, planning sprints. SkillzBench makes them trustworthy and measurable.

1 — A directory you can trust

Every skill in the directory went through the same pipeline:

  • Static scanning (deterministic, never opinion): secrets, binaries, hooks, exfiltration URLs, tool breadth.
  • License classification — permissive, copyleft, restrictive, none — with a serve-only-what-we-may policy.
  • Two independent LLM judges, then human review with mandatory admin two-factor before anything is published.

2 — Benchmarks, not vibes

Star counts tell you what's popular. SkillzBench tells you what works: each benchmarkable skill runs against category task suites on a reference agent, in two arms — with the skill and without. The difference is its Lift, published with a confidence interval and a trigger rate. Skills that don't help show honest negative numbers. See the leaderboard and the methodology.

3 — One MCP to serve them

The Skills MCP delivers your chosen loadout to any MCP client — progressive disclosure keeps context small, and enabling a skill is ask-by-default so agents never self-expand their permissions. Get a key →

4 — Everything is inspectable

  • Full methodology — scores, weights, limitations.
  • Skills also mirrored as plain git at github.com/SkillzBench/skills.
  • Community reviews (verified-use weighted) on every skill page.

Who it's for

Developers using Claude Code, Cursor, or custom agents who want proven skills instead of prompt-paste roulette. Teams who need one controlled library instead of every engineer vendoring their own. Skill authors who want evidence their skill actually helps.
